Configure variáveis de ambiente:\n   cp .env.example .env\n   Edite o arquivo .env com as credenciais e configurações necessárias\n4. Build e execução:\n   npm run build\n   npm start\n\nAlternativa com Docker:\n1. Build da imagem:\n   docker build -t cicada .\n2.

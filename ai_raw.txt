# Cicada Game

Cicada Game é um protótipo de jogo (web/mobile/desktop) focado em mecânicas de sobrevivência e exploração inspiradas nas cigarras. Este repositório contém código-fonte, assets e scripts para rodar e empacotar builds.

Atenção: Cicada está em versão BETA — recursos, equilíbrio e conteúdo ainda estão em desenvolvimento e podem mudar.

## Principais funcionalidades
- Exploração e coleta de recursos  
- Sistema de vida/energia com ciclos temporais (dia/noite)  
- Mecânicas de sobrevivência (fome, energia, perigo)  
- Arte e áudio básicos (substituíveis por assets finais)  
- Arquitetura preparada para extensões e melhorias

## Pré-requisitos
- Git  
- Node.js (v16+) e npm ou Yarn — caso o projeto seja web/JS  
- Ou o runtime/engine correspondente (Unity, Godot, etc.) dependendo da implementação

> Observação: adapte os comandos abaixo à engine/stack real do projeto (Unity, Godot, Phaser, React Native, etc.).

## Instalação (exemplo para projeto web/JS)
1. Clonar repositório:
   git clone https://seu-repositorio.git
   cd nome-do-repositorio

2. Instalar dependências:
   npm install
   # ou
   yarn install

3. Rodar em modo desenvolvimento:
   npm start
   # ou
   yarn start

4. Abrir no navegador:
   http://localhost:3000 (ou porta indicada no console)

## Build para produção
- Gerar build:
  npm run build
  # ou
  yarn build

- Artefato: diretório `build/` ou `dist/` (conforme configuração). Sirva com um servidor estático ou integre ao backend.
